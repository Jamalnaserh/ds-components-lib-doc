## Utilities

This library ships **utility classes** generated from design tokens. These are included in `dist/ds-components/ds-components.css`.

### How to use

- **In applications**: include the compiled CSS bundle (or your app’s build output that includes it).
- **In Storybook**: the preview loads `ds-components.css`, so utilities work out of the box.
- **Guideline**: prefer utilities for _layout + spacing + small visual tweaks_; prefer components for _structure + interaction_.

### Naming conventions

- **Tokens vs utilities**: design tokens are CSS variables (example: `--space-md`). Utilities are classnames (example: `p-md`).
- **Directional keys**:
  - padding: `p`, `px`, `py`, `pt`, `pr`, `pb`, `pl`
  - margin: `m`, `mx`, `my`, `mt`, `mr`, `mb`, `ml`
- **Composability**: utilities are meant to stack, e.g. `p-md radius-md shadow-sm bg-white`.

### Color utilities

- **Text**: `.text-{token}` (example: `.text-primary`, `.text-grey`)
- **Background**: `.bg-{token}` (example: `.bg-off-white`)
- **Border**: `.border-{token}` (example: `.border-light-grey`)

Tokens come from the DS color tokens (see **Foundations → Colors**).

### Spacing utilities

Generated from the spacing scale:

- **Padding**: `.p-{k}`, `.px-{k}`, `.py-{k}`, `.pt-{k}`, `.pr-{k}`, `.pb-{k}`, `.pl-{k}`
- **Margin**: `.m-{k}`, `.mx-{k}`, `.my-{k}`, `.mt-{k}`, `.mr-{k}`, `.mb-{k}`, `.ml-{k}`
- **Gap**: `.gap-{k}`

Where `{k}` matches the spacing keys (example: `xs`, `sm`, `md`, `lg`, `xl`).

### Typography utilities

- **Font weight**: `.fw-{key}` (example: `.fw-regular`, `.fw-medium`, `.fw-bold`)
- **Type scale**: `.text-{size}` (example: `.text-md`, `.text-lg`) — uses DS `font-size/line-height/letter-spacing` tokens
- **Numeric font size**: `.fs-{n}` for \(n = 13–90\) (example: `.fs-20`)
- **Line height**: `.lh-{key}`
- **Letter spacing**: `.ls-{key}`

#### Examples

</div>

### Radius / Shadow / Blur utilities

- **Radius**: `.radius-{key}`
- **Shadow**: `.shadow-{key}`
- **Blur**: `.blur-{key}` and `.backdrop-blur-{key}`

### Misc utilities

- **Text ellipsis**: `.text-ellipsis` (single-line truncate)
- **Screen-reader only**: `.sr-only` / `.visually-hidden`
- **RTL helpers**: `.flip-rtl` inside `[dir="rtl"]`
